# 수집·전처리·학습·실시간 판단

## 입력

ESP32 수신기는 CSI의 부호 있는 8비트 I/Q 배열과 시간·무선 정보를 USB 직렬 포트로 보냅니다. radio.py는 패킷 형식에 따라 배열 인덱스를 물리 서브캐리어로 바꿉니다. 사용하는 채널은 -26…-2, +2…+26의 50개이며 DC·±1과 가드 영역은 제외합니다. raw_iq_52라는 저장 형식 이름은 이전 기록과의 호환용 식별자이며, 현재 사용하는 유효 채널 수는 50개입니다.

I/Q로 진폭을 계산하고 장치 시간과 수신 시각을 정렬합니다. 신호를 60Hz 일정 간격으로 보간하되, 평균 수신량 30Hz 미만이나 0.15초 초과 공백이 있는 판단 구간을 학습·추론에 넣지 않습니다. 구간 양 끝의 신호도 0.04초 이내에 있어야 합니다. C6는 이득 준비가 끝나지 않았거나 구간 안에서 채널·형식이 바뀐 경우 제외합니다.

## 세 단계

1. **DWT**: 각 프레임에서 채널 진폭의 제곱을 전체 채널 전력 합으로 나눕니다. 공통 진폭 배율의 영향을 줄인 뒤 db4 웨이블릿을 2레벨로 분해합니다. 마지막 상세 계수의 MAD로 잡음 규모를 추정하고 그 0.5배를 soft threshold로 적용합니다.
2. **PCA**: 채널별 중앙값을 빼고 완성된 시간 구간마다 PCA를 맞춥니다. 변동을 설명하는 성분 3개를 보존합니다. 가장 큰 가중치가 양수가 되도록 각 성분의 부호를 고정합니다. 모든 성분이 시간 구간 사이에서 동일한 물리 운동을 뜻하는 것은 아닙니다.
3. **저역 통과**: 60Hz 표본에 8Hz 차단 주파수의 4차 Butterworth 필터를 앞뒤로 적용합니다. 완성된 구간을 처리하므로 실시간 화면도 최근 2·4·8·16초를 먼저 모아야 합니다.

최종 결과는 시간 × 3성분 배열입니다. signal_pipeline.py가 화면·학습·실시간 판단에 같은 처리를 적용합니다. 관찰 버튼을 모두 끄면 선택한 채널의 원본 진폭을 볼 수 있습니다. 학습은 관찰 버튼 상태와 관계없이 전체 전처리 결과를 사용합니다.

## 학습

체크한 기록을 선택한 길이의 겹치지 않는 구간으로 자릅니다. 같은 측정 회차의 구간을 학습·검증·최종 평가에 나눠 넣지 않습니다. 세 집합 각각에 모든 행동이 포함되어야 하므로 행동별 최소 3개의 독립 회차가 필요합니다.

학습 자료에서만 구한 성분별 RMS로 입력 크기를 조정합니다. CNN은 Conv1d 3층(16·32·32채널), 풀링, 길이 16의 adaptive average pooling, 64차원 완전연결층과 행동별 출력층을 사용합니다. AdamW, 클래스 가중치, label smoothing, dropout을 적용하고 검증 자료의 균형 정확도와 손실로 학습 단계를 선택합니다. 온도 보정도 검증 자료에서만 선택합니다.

최종 평가 회차는 모델 선택에 사용하지 않습니다. 화면의 균형 정확도는 최종 평가 자료에서 행동별 정답률을 구해 평균한 값입니다. 평가용 기록을 반복해서 보며 설정을 바꾸면 그 기록만으로는 더 이상 독립적인 최종 성능을 주장할 수 없습니다.

학습에 사용한 최종 파형과 회차·분할 정보는 모델 옆의 signals.npz에 저장됩니다. 그래프가 크게 출렁이는 것과 행동이 잘 구분되는 것은 다르므로 실제 독립 회차로 평가해야 합니다.

## 실시간 판단과 Pi

현재 수신 버퍼의 가장 최근 완성 구간을 같은 전처리 함수로 처리하고, 학습 때 저장한 크기 조정 값·CNN 가중치를 적용합니다. 최고 모델 점수 0.65 미만 또는 1·2위 점수 차이 0.15 미만이면 판단을 보류합니다. 연결이 끊기거나 새 신호가 없으면 이전 판단을 지웁니다.

수집 때 누른 행동 이름은 기록의 정답 라벨이며 실시간 답을 지정하지 않습니다. 학습하지 않은 행동을 완벽하게 거부하는 모델은 아닙니다.

PC의 학습은 PyTorch를 사용하고 PC/Pi의 추론 계산은 cnn_runtime.py의 NumPy 구현을 사용합니다. 모델 저장 전에 두 구현의 수치 일치를 검사합니다. Pi 내보내기에는 가중치, 설정, 실행 소스와 고지가 들어갑니다.

## C6 전송

송신기는 ESP-NOW HT20 MCS0 LGI 패킷을 초당 60회 전송하도록 구성되어 있습니다. 수신기는 지정한 송신 MAC의 CSI를 받습니다. 기본 무선 채널은 11이며 양쪽을 같은 1·6·11 채널로 설정할 수 있습니다.

수신 초반 120프레임은 이득 준비 구간입니다. 이득 정보·보상계수는 기록하지만 AGC 이득을 강제로 고정하지는 않습니다. 별도의 공통 배율 보상은 전력 비율 정규화에서 상쇄됩니다. 실제 전송률·손실·감지 범위는 현장에서 측정해야 합니다.
