WifiSensing 2.0 · WiFi-CSI-Sensing 데스크톱 앱

WifiSensing2.0.exe를 더블클릭하세요. Windows 10/11 64비트용이며 Python·Visual Studio 설치는 필요 없습니다.
포함된 라이브러리를 푸는 동안 첫 화면까지 수십 초 걸릴 수 있습니다.
기록과 모델은 같은 폴더의 WifiSensing2.0-data에 저장합니다. 기존 WifiSensing 1.0과 분리되어 있습니다.
다른 PC에 기록까지 옮기려면 폴더 전체를 복사하세요. WifiSensing2.0.zip은 새 설치용이며 개인 기록은 포함하지 않습니다.

1. 보드 연결
현재 공유기+ESP32는 [보드 연결]에서 USB와 2.4GHz Wi-Fi를 연결합니다.
C6 두 대를 사용하려면 [보드 연결 → C6 송신·수신 펌웨어 설치]에서 한 대씩 역할을 정해 설치합니다.
송신기는 전원으로 고정하고, 수신기 USB를 PC에 연결합니다. C6 전용 연결은 공유기·비밀번호가 필요 없습니다.
양쪽 기본 무선 채널은 11입니다. 바꿀 때는 송신기·수신기에 같은 채널을 적용하세요.
C6 실물은 아직 검증하지 못한 개발 펌웨어입니다. 자세한 준비 순서는 C6-준비와-실험순서.md를 읽으세요.

2. 신호 수집
정지·낙상은 기본 행동입니다. 다른 행동은 이름을 입력하고 저장하면 버튼으로 남습니다.
추가한 행동은 선택 후 삭제할 수 있으며, 행동 항목 삭제는 기존 기록을 지우지 않습니다.
행동·준비 시간·기록 길이를 정하고 수집 시작을 누릅니다. 완료한 기록을 직접 확인하고 라벨을 검토하세요.
한 측정 회차에서 모든 행동을 기록하고 [다음 측정 회차]에서 새로 수행합니다.
행동마다 최소 3회차가 필요합니다. 실제 실험에는 5~10회차 이상으로 시작하는 것을 권장합니다.
같은 기록을 여러 조각으로 나눠도 독립 회차가 늘어나지는 않습니다.

3. 기록 선택·학습
사용할 기록만 체크하고 [체크한 기록만 학습]을 누릅니다. 체크하지 않은 기록은 사용하지 않습니다.
더블클릭으로 라벨과 구간을 편집합니다. 여러 기록은 체크한 뒤 일괄 삭제할 수 있고 휴지통에서 복원합니다.
2·4·8·16초는 한 번 판단할 신호 길이입니다. 모두 학습할 필요는 없습니다. 정지·걷기는 2초 또는 4초부터 비교하세요.
선택 기록을 회차별로 학습·검증·최종 평가로 나눕니다. 검증으로 학습 단계를 고르고 최종 평가 결과를 표시합니다.
균형 정확도는 평가 자료의 행동별 정답률 평균입니다. 현재 행동의 확률이나 다른 장소에서의 정확도가 아닙니다.
현재 전처리 프로파일과 다른 형식으로 만든 모델은 다시 학습해야 합니다. 동일 프로파일 모델과 기존 기록은 보존합니다.

4. 실시간 인식
[이 모델로 인식하러 가기 → 실시간 인식 시작]을 누릅니다.
초록·파랑·주황의 전처리된 세 파형을 모두 사용해 새 신호를 판단합니다.
최고 점수가 65% 미만이거나 1·2위 차이가 15%p 미만이면 판단을 보류합니다.
신호가 끊기거나 0.15초보다 긴 공백이 있으면 해당 구간을 판단하지 않습니다.
모델 점수는 실제 정답 확률이 아닙니다. 학습하지 않은 행동을 완벽히 구별해내지는 못합니다.
보드 구성·무선 채널·배치가 달라지면 새로 수집하고 평가하세요.

전처리 버튼
유효한 물리 채널 50개 → 60Hz 정렬 → 전력 정규화·약한 db4 DWT → PCA 3성분 → 8Hz 저역 통과입니다.
버튼을 각각 누르면 현재 신호가 즉시 바뀌며 계속 갱신됩니다. 모두 끄면 선택한 채널의 원본 진폭입니다.
버튼은 관찰 설정입니다. 학습·인식에는 항상 모든 단계를 적용한 세 성분을 사용합니다.
3개 성분은 모두 표시되고 모두 학습합니다. 원본 I/Q도 향후 검토를 위해 기록에 보존됩니다.

라즈베리파이
PC에서 학습 후 [라즈베리파이 모델 내보내기]를 누르면 모델·수집·전처리·추론 코드가 ZIP으로 나옵니다.
ZIP 안의 PI-사용방법.md를 따르세요. Pi에서 새 라벨 기록을 모아 PC에서 가져와 학습할 수 있습니다.
실제 Pi 속도와 C6 행동 인식 성능은 보드 도착 후 확인해야 합니다.

현재 실험 결과와 미검증 범위는 검증결과-최적화.md에 적었습니다.
