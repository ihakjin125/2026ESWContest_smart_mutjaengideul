# C6 두 대로 시작하기

현재 펌웨어와 앱은 빌드·소프트웨어 검사를 완료한 개발 버전입니다. 이 공개본에서는 실제 전파, 보드 핀 구성, 장시간 수신, 행동 인식은 아직 검증하지 않았습니다.
기존 WifiSensing은 그대로 유지합니다. 이 버전의 기록과 모델은 WifiSensing2.0-data 안에 저장합니다.

## C6 연결 준비

1. 앱의 **보드 연결 → C6 송신·수신 펌웨어 설치**를 엽니다.
2. 보드를 한 대씩 USB로 연결하고, 포트와 역할을 선택합니다. 한 대는 송신기, 다른 한 대는 수신기입니다. C6가 아니면 설치를 거부하며, 기존 전체 플래시 백업을 먼저 저장합니다. 일반적인 4·8·16MB ESP32-C6 개발 보드가 대상입니다.
3. 설치 후 송신기는 USB 전원으로 고정하고 수신기를 노트북에 연결합니다. 앱에서 **수신기의 USB 포트**를 연결합니다. C6 전용 모드는 공유기 이름·비밀번호가 필요 없습니다.
4. 양쪽 기본 무선 채널은 11입니다. 주변 간섭으로 끊기면 두 보드에 각각 같은 1 또는 6 채널을 적용한 뒤 새 기록으로 비교하세요. 채널 변경 전후 데이터를 한 모델에 섞지 않습니다.
5. 보드를 고정하고 약 2초간 수신 이득 준비가 끝나길 기다립니다. BOOT/RESET 조작이 필요한 보드는 설치 오류 안내와 제품 설명서를 확인하세요. 다른 칩용 파일을 강제로 설치하지 않습니다.

## 먼저 통신과 배치를 확인

- 송신기·수신기를 약 2~3m 간격으로 고정하고 사람은 두 보드 사이에서 움직이는 것으로 시작하세요. USB 케이블·보드·송신기 자체를 움직이지 마세요. 이 배치는 시작 조건이며 공간마다 조정이 필요합니다.
- 수신 목표는 초당 60프레임입니다. 앱의 실제 수신 Hz와 끊김을 확인하세요. 한 판단 구간에 평균 30Hz 미만이거나 0.15초보다 긴 공백이 있으면 학습·인식에서 제외합니다.
- 정지 20초 → 걷기 20초 → 정지 20초를 새로 수행하며 원본과 각 전처리 단계를 비교하세요. 버튼을 모두 켜면 최종 3성분이며, 모두 끄면 선택한 채널의 원본 진폭입니다.
- 세로축 고정을 켜고 같은 단계에서 비교하세요. 단계마다 단위가 달라 단계 변경 시 한 번 축을 맞춥니다. 큰 파형이 곧 좋은 분류 성능을 뜻하지는 않습니다.
- 전처리가 사람의 행동과 무관한 모든 흔들림을 구별해서 없애지는 못합니다. 빈방에서도 계속 흔들리면 보드 위치·전원·주변 사람·채널·수신 공백부터 확인하세요.

## 실험 데이터를 모으고 학습

1. 정지·걷기 두 가지부터 시작합니다. 같은 회차에서 모든 행동을 20~30초씩 수집합니다.
2. **새 회차**를 누르고 각 행동을 다시 수행합니다. 파일 복사나 같은 동작 기록의 여러 조각을 독립 회차로 세면 안 됩니다. 최소 행동별 3회차가 필요하며, 실험에는 5~10회차 이상을 권장합니다.
3. 기록을 열어 라벨과 실제 행동 시점을 확인합니다. 필요한 구간만 잘라 저장하고, 사용할 기록만 체크합니다. 낙상 기록의 전후 정지까지 전부 낙상으로 라벨링하지 마세요. 실제로 넘어지는 위험한 실험 대신 매트 등 안전한 조건의 모의 동작으로 먼저 확인하세요.
4. 정지·걷기는 2초 또는 4초 중 하나로 시작하세요. 호흡처럼 느린 변화에는 8·16초를 별도로 비교할 수 있습니다. 모든 길이로 학습할 필요는 없습니다. 8Hz 저역 통과는 통과 상한이며 0.2~0.4Hz 호흡 성분도 통과하지만, 그것만으로 호흡을 알아내는 것은 아닙니다.
5. **체크한 기록만 학습**을 누릅니다. 측정 회차가 겹치지 않게 학습·검증·최종 평가를 나누고, 검증으로 선택한 CNN을 마지막 평가 자료에 한 번 적용합니다.
6. 평가 표에서 행동별 정답률과 혼동한 행동을 확인하세요. 실시간 인식 화면에서는 학습 때와 같은 구성·채널·판단 길이를 사용합니다. 기록 수집 때 골랐던 행동 버튼은 실시간 답에 영향을 주지 않습니다.
7. 최고 모델 점수 65% 미만 또는 1·2위 차이 15%p 미만이면 판단 보류입니다. 점수는 실제 정답 확률이 아닙니다. 학습하지 않은 동작을 완벽히 거부하는 기능도 아닙니다.

## 처리 방식

유효한 물리 서브캐리어 50개 → 60Hz 일정 간격 정렬 → 프레임별 전력 비율 정규화 및 db4 DWT(2레벨, 약한 임계값) → PCA 3성분 → 8Hz Butterworth 4차 필터 → 3성분 전체를 1D-CNN 입력으로 사용합니다.

DC와 ±1, 가드 영역, 유효하지 않은 첫 영역을 제외합니다. 칩/패킷 형식에 따라 배열 위치를 다르게 해석합니다. 구형 파일은 가능한 경우 원본 I/Q로 메모리에서 교정하며 파일 자체를 다시 쓰지 않습니다.
정규화는 공통 진폭 배율을 상쇄합니다. C6 펌웨어는 AGC·FFT 이득과 보상계수를 기록하고 준비 구간을 제외하지만, 수신 이득을 강제로 고정하지는 않습니다. 보상계수를 따로 곱한 효과는 이 전력 비율 정규화에서 상쇄됩니다.
화면의 초록 PC1·파랑 PC2·주황 PC3가 모두 학습 입력입니다. 완성된 각 시간 구간을 같은 함수로 처리합니다. CNN 입력 크기 조정은 학습 자료에서만 구한 성분별 RMS를 사용합니다.
전처리·학습 매개변수와 검증 범위는 ARCHITECTURE.md에, 외부 코드 출처는 NOTICE.md에 정리되어 있습니다.
현재 전처리 프로파일과 다른 형식으로 만든 모델은 다시 학습해야 합니다. 동일 프로파일 모델과 기존 기록은 보존합니다.
