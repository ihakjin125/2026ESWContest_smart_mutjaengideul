# WiFi-CSI-Sensing

**멋쟁이들** 팀의 제24회 임베디드소프트웨어 경진대회 LG전자 부문 프로젝트를 위한 Wi-Fi CSI 수집·학습·인식 모듈입니다.

ESP32에서 수신한 CSI를 관찰하고, 사용자가 이름을 붙인 행동 기록 중 선택한 것만 학습합니다. Windows 데스크톱 앱 이름은 **WifiSensing 2.0**입니다. 라즈베리파이 4/5에서는 수집·전처리·추론을 수행하고, 모델 학습은 PC에서 수행하는 구성입니다.

## 사용 흐름

1. **보드 연결**에서 USB 수신 포트를 연결합니다.
2. **신호 수집**에서 행동 이름, 준비 시간, 기록 길이를 정하고 기록합니다. 정지·낙상은 기본 항목이며 다른 행동은 추가·삭제할 수 있습니다.
3. DWT·PCA·저역 통과 버튼으로 실시간 파형의 각 단계를 확인합니다. 모두 켰을 때 보이는 PC1·PC2·PC3가 학습에 사용하는 최종 신호입니다.
4. **기록 선택·학습**에서 기록을 검토하고 필요한 기록만 체크한 뒤 학습합니다. 체크한 기록의 일괄 삭제·휴지통 복원도 지원합니다.
5. **실시간 인식**에서 학습한 모델로 새로운 신호를 판단합니다. 신호가 부족하거나 모델 점수가 낮으면 판단을 보류합니다.

행동마다 새로 수행한 측정 회차가 최소 3개 필요합니다. 같은 기록을 복사하거나 여러 조각으로 잘라도 독립 회차 수가 늘어나지는 않습니다.

## 장치 구성

| 구성 | 신호 경로 | 설정 |
| --- | --- | --- |
| 공유기 + ESP32 계열 수신기 | 2.4GHz 공유기 → 수신 보드 → USB → PC | 지원 펌웨어와 공유기 SSID·비밀번호 필요 |
| ESP32-C6 두 대 | C6 송신기 → ESP-NOW → C6 수신기 → USB → PC/Pi | 같은 무선 채널 사용, 공유기 비밀번호 불필요 |

C6 펌웨어는 앱에서 송신·수신 역할을 골라 설치할 수 있습니다. 기존 플래시를 백업하고 실제 칩 종류를 확인한 뒤 기록합니다. 공유기 방식의 보드 펌웨어와 설치 조건은 [빌드 문서](BUILDING.md)를 확인하세요.

## 실행

이미 빌드된 Windows 배포 폴더에서는 **WifiSensing2.0.exe**를 실행합니다. Python과 Visual Studio를 별도로 설치하지 않아도 됩니다. 최초 실행은 내장 라이브러리 압축 해제 때문에 시간이 걸릴 수 있습니다.

이 저장소는 소스 코드입니다. 소스 실행·실행 파일 생성 명령은 [BUILDING.md](BUILDING.md)에 있습니다. 생성한 대용량 실행 파일은 Git 저장소의 소스 파일 대신 GitHub Release 첨부 파일로 배포할 수 있습니다.

기록·모델·설정은 실행 파일 옆의 WifiSensing2.0-data에 저장됩니다. 소스 실행은 data-v2를 사용합니다. 기존 1.0 앱의 저장소와 분리되어 있습니다.

## 처리 방식과 검증 범위

물리 채널 50개를 60Hz로 정렬하고, 전력 비율 정규화·DWT → PCA 3성분 → 8Hz 저역 통과를 거친 전체 파형으로 CNN을 학습합니다. 관찰·학습·실시간 인식은 같은 전처리 함수를 사용합니다. 버튼을 끄는 것은 관찰 설정이며 학습 파이프라인은 항상 전체 단계를 적용합니다.

수집 원본 I/Q는 단계별 확인과 기록 구간 편집을 위해 보존합니다. CNN에 원본 통계 특징을 대신 넣지는 않습니다.

균형 정확도는 따로 떼어 둔 평가 회차에서 구한 **행동별 정답률의 평균**입니다. 현재 화면의 모델 점수와 다릅니다. 이 공개본의 자동 검사는 합성 입력으로 소프트웨어 기능을 확인합니다. **실제 C6 두 대와 Pi의 통신·속도·행동 정확도는 아직 검증하지 않았습니다.**

## 소스 구성

| 파일/폴더 | 역할 |
| --- | --- |
| app.py | 신호 수집, 기록 선택·학습, 실시간 인식 UI |
| server.py, services.py, teaching.py | USB 수집, 저장, 기록 관리, 학습 작업 |
| core.py, radio.py, live_timing.py | CSI 해석, 채널 매핑, 시간축 정렬 |
| signal_processing/, signal_pipeline.py | 단계별 전처리와 공통 파형 생성 |
| optimized_classifier.py, cnn_runtime.py | PC 학습과 NumPy 추론 |
| edge_runtime.py, edge_export.py | Pi 수집·추론 및 PC 모델 내보내기 |
| firmware-c6/ | C6 송신기·수신기 펌웨어와 배포 바이너리 |
| firmware/ | 공유기 방식 ESP32·C3 펌웨어 소스 |
