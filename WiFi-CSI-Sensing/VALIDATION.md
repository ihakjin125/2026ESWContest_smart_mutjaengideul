# 검증 방법

자동 검사는 보드 없이 생성한 합성 I/Q와 가상 직렬 응답을 사용합니다. 실제 행동 라벨을 가진 RF 측정 데이터가 아니며, 이 결과를 정확도 수치로 해석하지 않습니다.

검사 범위:

- 빈 상태의 UI, 사용자 행동 추가·삭제·재시작 복원
- 기록 선택·학습·가져오기·내보내기·일괄 삭제·복원
- 50채널 매핑과 단계별 관찰, 최종 파형의 학습 입력 사용
- 회차별 학습·검증·최종 평가 분리
- 오래된 신호·수신 공백·형식 변경 시 판단 보류
- PC의 PyTorch 및 NumPy 추론 수치 일치, Pi 번들 구성
- 가상 C6 설치에서 잘못된 칩 차단, 전체 플래시 백업 실패 시 쓰기 차단

재현 명령과 결과 파일 위치는 BUILDING.md의 자동 검사 절을 따릅니다.

실제 C6 두 대의 송수신, Pi 4/5의 실행 시간·전력·장기 운전, 새로운 장소·사람에 대한 행동 정확도는 아직 검증하지 않았습니다. 새 실험은 장치·장소·무선 채널을 기록하고 측정 회차를 분리하여 수행해야 합니다.
